# 使用手册（普通用户）

打开浏览器访问 `http://服务机IP:8080`，用管理员分配的账号登录。

顶部导航：**工作台**、**拍照**、**任务列表**、**检索**、**系统状态**（管理员会多一个**管理**）。

## 一、修改密码

登录后点右上角的**修改密码**，输入当前密码与新密码即可。首次登录请务必改掉初始密码——
初始密码文件（服务端的 `data\initial_admin_password.txt`）会在你改密成功后自动删除。

忘记密码无法自助找回（系统离线运行、不发邮件），请让服务管理员在服务机上执行：

```
python tools\reset_admin.py --username 你的用户名
```

会生成一个新的随机密码并打印出来。

## 二、批量导入图片

1. 进入「工作台」，默认来源是「图片」。
2. 选择图片：点「选择图片」多选、点「选择整个文件夹」整目录导入，或直接把文件拖进虚线框。
3. 可按需调整识别参数（语言、排版方案）——这些选项是从引擎实时读取的，换引擎会自动变化。
4. 点「开始导入并识别」。文件会逐个上传并显示进度，上传完自动进入识别队列，页面跳到任务详情。

支持格式：jpg / jpeg / jfif / png / webp / bmp / tif / tiff。

## 三、批量导入 PDF

1. 在工作台把来源切到「PDF 文档」。
2. 多选 PDF；如果是扫描件，建议勾选「生成双层可搜索 PDF」（在原扫描图上叠加文字层，
   之后可以复制、检索）。
3. 点「开始导入并识别」。

任务详情页会显示每个 PDF 的 `已识别页数 / 总页数`。识别完可下载双层 PDF（多个会自动打包成 zip）。

## 四、用摄像头拍照导入

拍照必须通过 **https** 访问，且客户端需先导入根证书（一次性），步骤见
[根证书导入说明](cert-guide.md)。

1. 进入「拍照」，浏览器会请求摄像头权限，选择允许。
2. 有多个摄像头时可在右上角切换；画面不对时点「重新连接」。
3. 点「拍摄」可连续拍多张；拍完在右侧点选某张，用「向左/向右旋转 90°」和
   在图上拖动框选后「应用裁剪」来调整，「还原」可以撤销到原始拍摄结果。
4. 填任务名称（可不填），点「开始识别」。

## 五、查看与校对结果

任务详情页左侧是文件列表（状态、字数、耗时），点任意一项，右侧显示原图与识别文本：

- 直接修改文本框内容，点「保存校对结果」保存；
- 「下载该项 txt」导出单个文件；
- 顶部按钮可导出全部或仅成功项：txt / csv / **Excel**，PDF 任务还能导出双层 PDF。

## 六、任务管理

「任务列表」可按状态筛选，支持：**取消**（排队或进行中的任务）、**重试失败项**、
**删除任务**（连同文件一起删除）。列表页会显示 `已完成 / 总数` 与失败数。

调度是按用户轮转的：别人提交的几百张图片不会把你的任务一直堵在后面。

## 七、历史检索

「检索」页输入关键字，会在**任务标题**、**文件名**和**识别文本开头**中查找。
要检索完整正文，请到任务详情页导出该任务的 txt/Excel 后再搜索。

## 八、常见问题

**任务一直显示"排队中"**
说明识别线程正忙或引擎不可用。到「系统状态」看引擎是否在线、队列积压多少。多人同时用时会排队，属正常。

**某个文件识别失败**
任务详情页里该项会显示失败原因（例如"文档已加密，请提供密码"）。处理完可点「重试失败项」。

**识别结果里出现无关文字（例如水印、页眉页脚）**
可以在导入时通过识别参数中的忽略区域设置排除，或识别后在结果里手工删除并保存。
