# 根证书导入说明（客户端侧）

## 为什么必须做这一步

浏览器规定：只有**安全上下文**（`https://` 或以 `localhost` 访问）才允许网页调用摄像头。
本系统部署在局域网里、用 `http://服务器IP:8080` 访问，属于非安全上下文，因此拍照功能会被
浏览器禁用（导入图片、导入 PDF、查看结果都不受影响）。

后端已经提供 https 监听（默认 8443 端口）并自带自签证书。自签证书不被操作系统信任，
所以每台需要拍照的客户端电脑要做一次「导入根证书」的操作。只需做一次。

## 第一步：服务端确认证书与地址匹配

证书里写死了它适用于哪些地址（SAN）。**证书里的 IP 必须和你实际访问用的地址一致**，
否则浏览器会报 `ERR_CERT_COMMON_NAME_INVALID`。

服务器上用 `tools\gen_cert.py` 生成时，默认会自动带上本机 IP 与主机名。如果服务器有多张
网卡、或你想用某个固定域名访问，请显式指定：

```
.\.venv\Scripts\python.exe tools\gen_cert.py --force --san 192.168.1.50,ocr-server
```

查看当前证书覆盖了哪些地址：命令执行完会打印「生效的主机名 / 生效的 IP」。

## 第二步：客户端导入根证书

先确认你能用 http 打开系统（`http://服务器IP:8080`），然后任选一种方式。

### Windows（Chrome / Edge）

1. 下载根证书：浏览器访问 `http://服务器IP:8080/api/system/root-cert`
   （这个接口不需要登录，就是为了方便这一步）。
2. 双击下载到的 `my-ocr-root-ca.cer` → 「安装证书」→ 存储位置选**本地计算机**（需要管理员）→
   「将所有证书都放入下列存储」→ 浏览 → 选**受信任的根证书颁发机构** → 完成。
3. 会弹出安全警告，确认即可。
4. **完全关闭并重新打开浏览器**。
5. 访问 `https://服务器IP:8443`，地址栏应显示锁标志且无证书警告，此时「拍照」页面可以调起摄像头。

也可以用管理员身份运行 `tools\import_root_cert.bat`（把 .cer 放在同一目录），效果相同。

### macOS（Safari / Chrome）

1. 下载 `my-ocr-root-ca.cer`。
2. 双击 → 加入「钥匙串访问」的**系统**钥匙串。
3. 在「钥匙串访问」里找到 `My OCR Internal CA`，双击 → 展开「信任」→ 把「使用此证书时」改为
   **始终信任** → 关闭窗口并输入密码确认。
4. 重启浏览器，访问 `https://服务器IP:8443`。

### Firefox（Windows / macOS）

Firefox 默认不信任操作系统的证书库，二选一：

- 在地址栏打开 `about:config`，把 `security.enterprise_roots.enabled` 设为 `true`，重启 Firefox；
- 或手动导入：设置 → 隐私与安全 → 证书 → 查看证书 → 证书颁发机构 → 导入 → 选择
  `my-ocr-root-ca.cer` → 勾选「信任由此证书颁发机构来标识网站」。

## 第三步：验证

1. 访问 `https://服务器IP:8443`，登录。
2. 进入「拍照」，浏览器会询问摄像头权限，选择「允许」。
3. 能看见实时画面即成功。可连续拍摄多张，拍完在右侧点选，用旋转与裁剪调整后再提交识别。

## 常见问题

**报 `NET::ERR_CERT_AUTHORITY_INVALID`**
证书没导入成功，或导入到了「个人」而不是「受信任的根证书颁发机构」。重新导入并重启浏览器。

**报 `NET::ERR_CERT_COMMON_NAME_INVALID`**
证书里的地址（SAN）与你访问用的地址不一致。常见原因是换了 IP 或用主机名访问但证书里没有。
按第一步重新生成证书（加 `--san`），然后客户端重新导入。

**https 能打开，但拍照页面提示权限被拒绝**
地址栏左侧点锁/摄像头图标，把摄像头权限改为「允许」后点页面上的「重新连接」。

**换了浏览器却又要导入一次**
Windows 上 Chrome/Edge 共用系统证书库；Firefox 用自己的，需按上面单独处理。

**摄像头提示被占用**
关掉系统「相机」应用、会议软件等占用摄像头的程序再重试。

## 安全说明

根证书（`data/certs/ca.key`）与服务器私钥（`data/certs/server.key`）是敏感文件，只应留在服务器上，
**不要**随客户端安装包分发。分发给客户端的只有 `ca.cer` 这一个公钥文件。
